Week 6 - JQuery

For this week's exercise, I have added jQuery to my web application. I managed to simplify the code quite a bit. Previously, I was setting two arrays based on class names and then having to run through them to first clear the webpage of the old data and then show the section cards again.

I was considering writing a function for showing and hiding the section cards, but I managed to reduce this to three simple lines of code, with no function needed: 

$(".mealId").html("");
$(".meal").hide();
$(".meal").show();

I have also added a fade effect for the cards that are displayed. I like this addition as it makes the experience feel a little smoother.

For testing purposes, I made a few of the sections hidden by default and turned the titles into toggle buttons. This isn't required, but it allows me to explore jQuery further.

The button I was probably most pleased with was the title of the dish. The title is initially blank, but the script adds the name of the dish once the API data has been loaded. I then used the title as the clickable element to show and hide the thumbnail. I like this because the same element is being populated dynamically and then used as part of the interaction.

The buttons don't look particularly visually appealing at the moment, but for the sake of this exercise, I am happy to leave them as they are. If I were to implement this properly, I would make them smaller and make it more obvious that they are buttons.
